2. Database Schema Details

Table Users

Column Data Type Constraints Description
id BIGSERIAL PK, Auto Increment Unique identifier for the user.
username VARCHAR(50) UNIQUE, NOT NULL Username for system login.
password_hash VARCHAR(255) NOT NULL Hashed password to ensure security.
role VARCHAR(20) DEFAULT 'SUPPORT', NOT NULL Defines user privileges and access levels (e.g., ADMIN, SUPPORT).
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, NOT NULL Record creation timestamp.

Table Nodes

Column Data Type Constraints Description
id BIGSERIAL PK, Auto Increment Unique identifier for the network node.
name VARCHAR(100) NOT NULL Alias for the node (e.g., BTS_Dandy_Mall).
ip_address VARCHAR(45) UNIQUE, NOT NULL IP address of the server or telecom element.
port INTEGER DEFAULT 162, NOT NULL Listening port for SNMP traps.
location VARCHAR(255) NULL Physical location of the node.
description TEXT NULL Optional extra details about the node.
status node_status (ENUM) DEFAULT 'UP', NOT NULL Current operational status of the node (UP, DOWN, WARNING, UNKNOWN).
node_type VARCHAR(50) NULL The category/type of the telecom node (e.g., BTS, MSC).
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, NOT NULL Record creation timestamp.

Table Trap_Actions

Column Data Type Constraints Description
id BIGSERIAL PK, Auto Increment Unique identifier for the configured action.
node_id BIGINT FK (nodes.id), NOT NULL The specific node associated with this automated action.
trap_oid VARCHAR(150) NOT NULL The SNMP Object Identifier triggering the action.
trap_name VARCHAR(100) NOT NULL Human-readable name for the trap.
severity trap_severity (ENUM) NOT NULL Severity level (INFO, MINOR, MAJOR, CRITICAL).
action_name VARCHAR(100) NOT NULL Name of the action to execute.
action_type VARCHAR(20) NOT NULL The type of automated response to execute ('SMS', 'EMAIL', 'SCRIPT').
target_payload VARCHAR(255) NULL The target destination (Phone number, Email, or Script path).
auto_resolve BOOLEAN DEFAULT FALSE, NOT NULL Flag to indicate if the trap auto-resolves.
description TEXT NULL Details about the action.
Composite Constraint: UNIQUE(node_id, trap_oid) - Prevents defining duplicate actions for the exact same trap OID on the same Node.

Table Trap_History

Column Data Type Constraints Description
id BIGSERIAL PK, Auto Increment Unique identifier for the received SNMP trap history record.
node_id BIGINT FK (nodes.id), NOT NULL The node that generated and sent the trap.
trap_action_id BIGINT FK (trap_actions.id), NULL Reference to the specific action triggered (if any).
trap_oid VARCHAR(150) NOT NULL The OID payload of the received trap.
source_ip VARCHAR(45) NOT NULL IP address from where the trap originated.
message TEXT NULL Details of the error or the constructed log message.
status trap_status (ENUM) DEFAULT 'OPEN', NOT NULL Lifecycle status (OPEN, ACKNOWLEDGED, RESOLVED).
received_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, NOT NULL Timestamp marking when the trap was captured.
resolved_at TIMESTAMP NULL Timestamp marking when the issue was resolved.
resolved_by BIGINT FK (users.id), NULL Tracks which user marked the issue as resolved.
